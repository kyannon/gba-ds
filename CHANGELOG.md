# Changelog

## v1.6.5 (2026-11-27)

### Widescreen patches
- **Widescreen patches.** A game with a GBA DS widescreen patch can be played wider (16:9, 16:10) or taller (4:3), at your screen's shape, showing more of the game at its sides (or above and below), drawn by the game itself. Where GBA DS has a patch for your game and your screen, the game's Patches menu offers to download it and switch it on (A, then A again); once downloaded it's a patch like any other, and only one widescreen patch is on at a time. The picture keeps its shape whatever the game screen scale (Pixel Perfect stays Pixel Perfect, every other scale shows it at Full Width), and the second screen stays as it was. No game has one yet: they'll come game by game, starting from a test ROM. Known: pictures of resume points and bug reports show the middle 240×160 only; LCD ghosting and run-ahead act on the middle only; the new menu text isn't translated yet; downloads haven't been tried on Android, and the web player has none.
- **The web player's wide view**, at kyannon.github.io/gba-ds/wide: the web player with one more setting in its bar, Wide view (16:9, 16:10, 4:3 or off), that draws any game wider or taller than the GBA's screen, changing as you pick, to see what a game shows past its edges. Everything else is the web player as you know it, with the same settings and saves.

### Single displays
- **The game list always shows the selected game** (issue #84). On a tablet, a phone or another single display, the game list used to show the list alone with One display on Game only, or where the display was too small or the wrong shape for two screens, so the selected game's details (and the ROM path) never showed. Now the list sits under a short strip across the top with GBA DS's logo, the game's logo, whether it has a save state, Play and Quit, the version, any romhack or modified ROM note and, with Show ROM Path on, the game's file. Where the display has room for both screens, nothing changes. On a tall, narrow display the list's buttons now fit across it too.

### Display
- **Edge stretch, a new game screen and second screen scale.** Display > Game screen scale and Second screen scale have **Edge stretch**: the picture fills the screen like Stretch, but the edges are stretched more than the middle, so what you look at keeps closer to its shape (sideways on wide screens, up and down on 4:3 ones such as the RG DS Plus).
- **Web player: the Scaling filter's upscalers** (Scale2x to OmniScale) now work there too. Known: how fast the heavier filters run in the web player hasn't been measured.

### Menus
- **The ROM path on the game list can be bigger.** Settings > System > Show ROM Path on Game List now steps through Off and On at four font sizes, 1x (as before) to 4x, for reading the path on a big display or from further away. At the larger sizes a long path takes more lines, and on the RG DS Plus the save state's picture above it gets smaller to make room. If you had it on, it stays on at 1x.

### Android
- **Save states shared with RetroArch on Android too** (issue #111): the game list's Settings now has **Save States: Shared with RetroArch** and **RetroArch's State Folder**, as on Linux, so the pause menu's slots 0 to 9 and the resume point can be RetroArch's own (save in one, go on in the other, or on another device you sync the folder with). GBA DS finds them in `RetroArch/states/mGBA` on your storage; choose another folder with **RetroArch's State Folder** (needs All files access). Known: RetroArch builds that keep their states inside `Android/data` can't share them, as Android keeps other apps out of that folder: set RetroArch's Settings > Directory > Save States to a folder on your storage first.

### Fixes
- **The game list shows every game in a big folder.** With All on and more than 256 games, the list stopped drawing after the 256th: the rest could still be picked, but their rows were blank. Every game is shown now, in the list and in both grids.
- **When no supported games are found**, the game list now says to tap Supported to see every game, instead of pointing to a line in the settings file.
- **A few more words translated:** "(patch)" after a patched game's name, and "Downloading", "Installing" and "Installed" on the Updates screen.
- **Game Boy games in the web player** could overwrite a little of the player's memory as they started (GBA cartridge rumble was being set up for them too). Fixed; on handhelds and Android it did no harm.
- **A game that fails to load** no longer leaves its memory in use until GBA DS is closed.

The game only shows some of them for a moment after they change; on the second screen they're always there, and the game screen shows the table alone. - **Shantae Advance: Risky Revolution** (Limited Run Games' 2024 cartridge; pull request #103 by cmyksoda): in play, the second screen shows the HUD (the held item's circle with the magic bar, the hearts, the gems and the dance indicator) in its own corners over the game's logo, on black, and the game screen has none of it. For a talk, the HUD slides off the second screen as it does on the game's own; the game's pause screen shows the logo. The cartridge's header has no game code, so GBA DS knows it by its checksum: a ROM changed in the file itself plays as an unsupported game (a patch switched on in Extras > Patches is fine). Known: dances, transformations, dungeons, shops and Battle Mode haven't been tried.
- **Shin Megami Tensei II** (Japan; pull request #106 by cmyksoda), with its English translation (a port of the Super Famicom game's), as a patched ROM or as an `.xdelta` patch. As in Shin Megami Tensei, while you walk a dungeon or a town the second screen shows the game's own automap (the one you open with L), with the compass, the floor's name and your map markers, kept up to date as you walk and turn. Where a floor is taller than the game's map window, the second screen shows more of it above and below, over the game's own grid, without the game's scroll arrows. Fights, menus, conversations and the rooms between dungeons keep the last map; the title and a new game's training room show the logo. Known: a step that starts a conversation (the Virtual trainer's exit, the Virtual Battler's door) keeps the map from before that step; with the translation, the Virtual Battler's levels keep their Japanese names; stairs, the overworld, shops and later dungeons haven't been tried.

### Display
- **Scaling filter: upscaling filters that round off pixel-art edges** (issue #89). Display > Smooth scaling is now **Scaling filter**, in the pause menu and in the game list's Settings. Besides **Sharp** and **Smooth** (as before), it has **Scale2x**, **Scale4x** and **hq2x**, which redraw the game's pixels with smoothed edges before the picture is enlarged, at full speed on the RG DS Plus, and **MMPX**, **xBR-lv2**, **xBR-lv3** and **OmniScale**, heavier filters for stronger devices. Where the graphics chip is known to be too slow for the heavy four, such as the RG DS Plus's, they're greyed out and the game is drawn as with Sharp; where it hasn't been tried, they work, with a note that they may not run at full speed. While an upscaling filter is on, every shader is off on both screens, and the Shader rows are greyed. Your choice of Sharp or Smooth carries over. Known: the heavy filters haven't been tried on a device fast enough for them.

### Menus
- **Mute while fast forwarding** (issue #109). Fast forward's sped-up, high-pitched sound is now muted by default. To hear it again, turn off **Mute while fast forwarding** in Settings > Speed and sound, or in the pause menu's Speed and sound settings, right below Fast forward. Like the other settings there, it can be set for one game or for all.
- **Show the selected game's file in the game list.** Settings > System has a new switch, **Show ROM Path on Game List** (under GBA BIOS, off by default). On, the game list's other screen shows the selected game's folder and file name under Play and Quit, in small pixel letters below a thin line. Handy for telling two copies of a game apart.
- **The game list's GitHub link and version number are in the quick menu's pixel letters**, the link now in lower case. Those letters now also have `&`, brackets and the other symbols file names use, so quick-menu messages with them show in pixel letters too.

### Android
- **Phones with an 8BitDo FlipPad: the screens move up above it** (issue #107). The FlipPad folds over the bottom of a phone held upright and used to cover the bottom screen. While one is plugged in, both screens (or the game alone, and the pause menu) now fit in the part of the display above it, and they go back to the whole display when you unplug it. Settings > Screens > **Controller over the screen**: Automatic (the default), On for a controller of this kind that GBA DS doesn't recognise by name, or Off. Not used with the phone held sideways or on a device with two displays. Experimental: not yet tried with a real FlipPad; if the screens sit too high or too low, `pad_cover_mm` in the settings file says how much of the display it covers (64 mm by default).

### Fixes
- **A translation or romhack GBA DS knows now has its own logo** (pull request #102 by cmyksoda). With the Japanese game and its English translation both in your game list, each now shows its own title, in the list and on the second screen, instead of both showing whichever logo was made first: F-Zero Climax, Fire Emblem: The Binding Blade, Shin Megami Tensei and Densetsu no Stafy 1 to 3. A translation shows the Japanese game's logo until you've selected it once in the list. A logo made from a translation before this update stays on the Japanese game until you delete that game's logo file in the `states/logos/` folder (`BFTJ.png` for F-Zero Climax, named by the game code).
- **One display: the game list keeps both screens after you close a game** (issue #108). With One display set to show both screens, closing a game from the pause menu brought the game list back over the whole display, without the selected game's screen. Now the game list always shows like a two-screen device, the list on one screen and the selected game on the other, unless your display is too small or the wrong shape for that, where it shows the list alone. The game list's Settings now takes the whole display while it's open, like the pause menu. On a tall display (a tablet or phone held upright), Settings' buttons now put their picture above the name and description and wrap the text, so it's no longer cut off.
- **RG DS Plus on the Stock Linux OS: the left stick's left and right are no longer swapped** (issue #104). The controls GBA DS ships for that system had the stick's left and right the wrong way round, in the menus and in games. A mapping you made yourself with Map Buttons still comes first.

## v1.6.3 (2026-11-25)

### New games
- **Pokémon Mystery Dungeon: Red Rescue Team** (USA and Australia, Europe, and Pokémon Fushigi no Dungeon: Aka no Kyuujotai in Japan; pull request #94 by cmyksoda): in a dungeon, the second screen shows the floor map and the status line (the floor, your level and HP), live, with the status line centred at the top; the game screen shows the field alone. Menus and messages stay on the game screen, while the status line stays on the second screen and keeps up with your HP. Taking the stairs, the old floor's map stays until the new one comes up. Outside a dungeon, the second screen shows the logo. With two screens, SELECT does nothing on a dungeon's field, since all it does there is show the map the second screen already has; in the menus it works as usual. Known: with the game's Map option at Off the second screen has only the status line, and at Shade the map is dithered as the game draws it; a state saved with the game's own map view on has a black game screen until you press SELECT; boss scenes and the end of a dungeon haven't all been tried.

### AYN Thor on Armada
- **The second screen goes on the Thor's bottom panel in Armada's Game Mode, with its touchscreen** (issue #86, pull request #96 by cerroverb). Game Mode shows only the top panel and lends the bottom one to a program that asks for it; until now GBA DS put both screens on the top panel there. Now it asks for the bottom panel, draws the second screen on it, turned the way the panel is mounted, and reads its touchscreen directly, so the quick bar and the menus work there. Started from a Steam shortcut, `launch.sh` finds the panel and the touchscreen from Armada's own device profile. In the desktop, and on any other system, nothing changes. Experimental: tried on a Thor in Game Mode. New wiki page, [Install on Armada OS](https://github.com/kyannon/gba-ds/wiki/Install-on-Armada-OS). The request for the panel is a port of the DRM lease code in the Azahar-Enhanced fork (virtudude/azahar), see Licenses.

### Single displays
- **Both screens on one display** (issue #84). On a tablet, a phone or any single display, Settings > Screens > **One display** can now show the game and the second screen together, side by side or stacked (or automatically, by the shape of the display), instead of one at a time. **Second screen size** gives the second screen half, 40 % or 30 % of the display. The pause menu still fills the whole display. Game only stays the default, so nothing changes unless you turn it on. Tried on a Lenovo Legion Y700 (Gen 5).

### Menus
- **GBA DS asks which language to use the first time it starts after it's installed** (issue #92). Every language is listed by its own name, and the top screen says "Language" in all of them, so you can find yours even when the system reports a language you don't read (the RG DS Plus's stock Linux OS reports Chinese, which put every menu in Chinese). Pick one with A and both screens change to it straight away; press A again, START or Continue to keep it, or B to go back to the one it started in. Started straight into a game from your frontend, the game starts as usual and the question comes up the first time you open the pause menu. Updating GBA DS doesn't ask; you can still change the language in Settings > System > Language.

### Web player
- **A screen in a second window, for another monitor** (issue #93). On a computer, the new two-windows button in the web player's toolbar opens the bottom screen (the touchscreen) in a window of its own, to drag to another monitor; the player's window then shows the top screen alone, as large as it fits. Settings > Screens > Second window puts the top screen there instead. Keys, controllers and clicks on the touchscreen work in either window. The second window has its own Full screen button, at its top right when you move the mouse (with the top screen in it, a double-click works too). Pressing the two-windows button again, or closing the window, brings the screen back. In Chrome and Edge with more than one monitor, the window opens on the other monitor once you allow the player to place windows. The game keeps running when either window is hidden, so long as the other can be seen.

### Fixes
- **Starting a game from the game list no longer shows "Preparing the game..." while other games' logos are still being made.** With a large collection the list makes logos in the background, and starting a game waited for whichever one was under way, so the "First run only" screen came up on almost every start until they were all done. Now the other game's logo is put off until you're back in the list, and the screen only shows the first time a game's own logo is made.
- **Pokémon games and romhacks with a patch file beside them no longer show "Initializing game..." every time they start.** Their logo couldn't be made from the patched game, so it was tried again at each start; it now comes from the unpatched ROM file, the base game's logo. A logo that can't be found on a game's title screen is no longer tried again at every start either (a new version of GBA DS tries once more).
- **Settings > Updates' messages are in your language.** When checking for, downloading or installing an update failed, the message was in English whatever the menus' language; it now follows it (the technical detail after it, such as the server's answer, stays as it comes). The note in RetroArch's state folder picker when GBA DS can't save in a folder is translated too.
- **A battery save copied over on a full card is no longer left cut short.** On BananaOS, GBA DS copies a game's older save into the GBA list's saves folder; if the card filled up partway, the cut-off copy was kept as if it were whole. Now a copy that doesn't finish is removed, and the save it came from is untouched.
- **Emoji in a new version's release notes show properly** in the update notice, instead of as stray characters.

## v1.6.2 (2026-11-24)

### New games
- **WarioWare: Twisted!** (USA, and Mawaru Made in Wario in Japan): the game's gyro is played by turning the device. In Gyro mode, which every start begins in, the second screen is the game's logo on white that tilts with the device, with a **Touch!** button (or HOME + A). In **Touch mode** the touchscreen is a dial: touch anywhere and drag left or right to tilt the game that way, and let go to ease back to level; the second screen shows the game's menu wheel turning with it, with **Gyro!** and **Pause** buttons along the top. The dial's sensitivity (5% to 25%, 15% at first) is in the quick bar. The cartridge's motor is limited to short pulses here, since the gyro and the dial can make the game ask for far more rumble than the original's could. Known: no gyro sensor was found on the RG DS Plus under BananaOS yet, so there Touch mode is the way to play; the Europe release hasn't been tried; bug reports don't record the gyro.

### New: Super Game Boy border
- **Game Boy games that support the Super Game Boy can show their own border.** Display > Game Boy border > **Super Game Boy** (Castlevania Legends, Donkey Kong (1994) and the other "SGB Enhanced" games; greyed out for other games): the game's border fills the screen around its picture, at the Game Boy scale, with the Super Game Boy's colours. It counts from the next start, like the palette. The border is black until the game sends its own (a game that never does keeps a black one).

### Game list
- **A modified Game Boy ROM says so.** Under a Game Boy or Game Boy Color game's logo in the game list, a ROM that is not one of the dumps in No-Intro's Game Boy and Game Boy Color lists (a hack, a translation, a trimmed or bad dump) says "Modified ROM: not a known dump" ("Patched ROM..." when a patch made it so). It is only a note: the game plays as any other.
- **Sort the game list, and pin favorites to the top.** A bar of two buttons now sits at the top of the list, under the header, and scrolls away with the games: **A to Z** (as before) and **Recently played** (the game you played last first; games you haven't played yet follow, A to Z). Touch a button, or press Up from the first game, choose with Left / Right and press A. GBA DS remembers the sort you chose.
- **Favorites:** touch the star on a game's tile, or press **Y** with the game selected, to make it a favorite. Favorites are listed first, whatever the sort, and the star turns gold; do it again to take it off.

### RetroAchievements
- **Hardcore mode (still hidden until RetroAchievements approves it) now turns fast forward off**, as it does rewind, cheats and loading states, since GBA DS reads RetroAchievements' ban on frame advance as covering any speed-up. Fast forward still works in casual mode.

### Fixes
- **Game Boy: the Scanlines and Soft Cells shaders work.** With Display > Game Boy shader set to Scanlines or Soft Cells, a Game Boy game showed Display > Shader's pattern instead: the LCD grid, unless that was itself Scanlines or Soft Cells. GBA games were not affected.
- **Game Boy games' saved pictures show the real picture.** The picture under a game's name in the list (after a resume point is made) and the one beside a state in RetroArch's folder are now the Game Boy screen's own size, or the Super Game Boy border with its picture, instead of always the GBA frame. Take Screenshot already saved both screens as shown.
- **Game Boy: games that support the Super Game Boy show the colours they were made with** (issue #91). Castlevania Legends and the other "SGB Enhanced" games were grey; they now play as on a Super Game Boy (without its border) and show their own colours, with the default palette or with *Super Game Boy*. Choose DMG, Pocket, Light or Grayscale for those shades instead. A game started under the old setup starts over once instead of resuming.
- **Android: a second screen plugged in or taken out while a game runs is picked up** (issue #90). GBA DS looked at the displays only when the game started, so a USB-C screen connected or woken afterwards stayed unused until the game was started again. Now, about a second after a screen appears or goes, the game restarts once with the new layout and picks up where you were, even with Save on quit or Auto-load off. (Started from the game list, you come back to the list, with the game saved.) Not yet tried on a device.
- **Android: a gamepad's Back key is no longer taken for Select on pads that have both** (AYN Thor). Back now opens GBA DS's menus as it does on other devices, and Select stays Select. Not yet tried on a Thor.
- **Highlighted buttons and rows have the same round top corners as bottom ones.** The top corners of a lit or selected button (the pause menu's tabs, the quick bar, the game list's buttons) were nearly square next to the bottom ones.
- **Pokémon: the Town Map shows on the second screen in FRLG+ 1.5.1**, the FireRed romhack (BPS patch or ROM). Its Bag wraps round from the last pocket to the first, so the map was never found and only the Party showed. GBA DS now finds the Key Items pocket by its tab, in any Bag that wraps. FRLG+ 1.5.1 is added to the tested romhacks.
- **Rumble patches that stop the motor by switching the cartridge's motor pin off no longer leave the device rumbling.** Mario & Luigi: Superstar Saga's rumble patch started rumbling in the story intro and never stopped; it now stops when the game says so.

## v1.6.1.1 (2026-11-23)

### New: Game Boy and Game Boy Color games (issue #77)
- **GBA DS plays Game Boy and Game Boy Color games**, on one screen with the other idle dark grey, as a GBA played them. Put `.gb` and `.gbc` files (or zips) in your GBA folder or in `gb` / `gbc` folders beside it, set **Games shown** to **All**, and start them from GBA DS's own game list. Saves, save states, rewind and cheats work as for GBA games. Details on the new wiki page, [Game Boy games](https://github.com/kyannon/gba-ds/wiki/Game-Boy-games).
- **New Game Boy rows** in the pause menu's Display page (and Settings > Display), for these games only: **Game Boy size** (the GBA frame, or the Game Boy's 160×144 picture as the whole screen) and **scale** (Pixel Perfect, Fit, Stretch); **palette** for monochrome games (Game's own, DMG, Pocket, Light, Grayscale, Super Game Boy); **Dual-mode games** in colour or in monochrome; **color correction** (as GBA, off, Game Boy Color, Game Boy Advance); **ghosting** (as GBA, off, light, smart, strong); and a **shader**, with a **Dot matrix** look. The ones that don't apply to the game are greyed out. Palette and dual-mode changes count from the next start: closing the menu asks to **restart now** or **discard changes**, and a resume point made with other colours isn't resumed.
- Known: the shades, the Game Boy Color's colour matrix and the dot matrix are first guesses; screenshots and the quick bar's pictures use the GBA frame; no Super Game Boy borders, rumble, camera or link cable; no RetroAchievements; EmulationStation, BananaOS and Android frontends don't start these games yet; no list of known dumps yet (no "Modified ROM" note).

### RetroAchievements
- **Unlocks earned while the connection is down are no longer lost if you close GBA DS first.** They wait in `states/ra/pending.txt` and are sent the next time you sign in, before the game's achievements load. (Before, they were only retried while GBA DS stayed open.)
- **Rich Presence** shows under your totals in the Achievements page: the line RetroAchievements shows on your profile for the game.
- **Challenge and progress indicators**: while an achievement's challenge is under way its badge sits at the bottom left of the second screen, and a measured achievement shows its progress (50/5,000) for a few seconds when it changes.
- **Leaderboard popups and a running value** are ready (started, failed, submitted, your rank) but only appear in hardcore mode, which isn't on yet.
- **GBA DS now says which mGBA it runs** to RetroAchievements (`GBADS/1.6.1.1 (Linux) mgba/0.11.0 ...`), with the version as numbers only.
- **Hardcore rules are built, but hidden for now.** GBA DS can already play by RetroAchievements' hardcore rules (no loading states, rewind, cheats or bug reports, and the game starts over when the mode changes), but RetroAchievements hasn't approved it yet, so the menu item stays out of sight until they do. GBA DS earns casual achievements as before.
- New wiki pages, Privacy and Licenses: what GBA DS sends and keeps, and what it is built from.

### Changes
- **Rewind and fast forward can go on other buttons** (issue #88). Settings > Controls > Hotkeys has Rewind (hold) and Fast forward (hold), L2 and R2 at first (HOME + L2 and HOME + R2 work too), and two new shortcuts, Rewind on/off and Fast forward on/off, that keep going until you press them again (no button until you give them one). The Hotkeys list now scrolls, and its last row is no longer hidden under the note at the bottom. Map buttons and Hotkeys are now at the top of Controls, and they (and the state folder picker) show on the menu's screen only, not on both.
- **F-Zero Climax: Time Attack, Survival and Course Edit's test run work well.** v1.6 had only Grand Prix checked; the player who contributed the game support has now tried the other three, and they work well.
- **Android: a second screen on a USB-C display is chosen more carefully, and `launch.log` lists the screens** (issue #65, AYN Odin 2 with the Retroid Dual Screen Add-on). GBA DS now prefers the display Android marks for presentations, then one that is switched on, instead of the first one listed, and `launch.log` has a line for each display Android reports (name, size, flags, state) and which one was used. Known: a screen plugged in after the game has started isn't picked up until the game is started again.

### Fixes
- **The pause menu's notes are no longer cut off in other languages.** A long translated note (French, German...) stopped mid-word, and the end of "Choose it again to close GBA DS: your place is saved" stayed in English in every language.
- **Cheats with the same name are remembered separately.** When a cheat file had two cheats with the same name, switching one on brought both back on the next time the game started. Your existing choices still load as before.
- **Choosing a RetroArch state folder with a very long path** (over 511 characters) now says the path is too long, instead of quietly saving a cut-off path that pointed somewhere else.
- **A game started after Pokémon Pinball: Ruby & Sapphire no longer shows its status bar on both screens.** Going back to the game list from Pokémon Pinball and starting a game whose status bar moves to the second screen (Super Mario Advance 4, for one) left the status bar on the game's screen too, and on Super Mario Advance 4's world map a few of its rows. ## v1.0 (2026-10-13)

First release. GBA DS is a Game Boy Advance emulator for dual-screen handhelds (built for the Anbernic RG DS Plus on ROCKNIX) that keeps the game's own map on the second screen, the way the DS Castlevanias do.

**Games with a live map**
- Castlevania: Aria of Sorrow, Harmony of Dissonance, Circle of the Moon (USA). Circle of the Moon also shows its completion rate, copied from the pause screen.
- Metroid: Zero Mission and Metroid Fusion (USA): the whole pause screen with its frame, lettering and button prompts erased, and the HUD mini-map hidden.
- The Legend of Zelda: A Link to the Past (USA): the zoomed-out world map outdoors, dungeon maps once you have them; dimmed where no map is available. Four Swords is left off the list (it needs linked GBAs).
- Every other GBA game plays normally on one screen.

**App**
- Game list of logo tiles pulled from each ROM; touch or D-pad.
- Pause menu (tap the screen or HOME): save / load state, restart, swap screens, scaling (pixel perfect / full width / stretch), LCD grid, overlays, FPS counter.
- Automatic resume: leaving a game saves where you were.
- Overlays: generated map surrounds, plus your own PNGs for the primary (game) and secondary (map) screens, per game or for every game.
- Everything game-specific (logos, map borders) is extracted from your ROMs; no game art is shipped.

**Install:** unzip `gba-ds-v1.0-rocknix-aarch64.zip` into `/storage/roms/ports/`, keep unzipped `.gba` ROMs in `/storage/roms/gba/`, and launch **GBA DS** from Ports. See the README for details and for upgrading from the old `gbadual` builds.
