GBA DS's default overlays: a bezel round the picture, for each screen of the devices GBA DS knows
(docs/devices.csv). Made by tools/make_overlays.py; don't edit them here (your own overlays go in
overlays/, and win over these). A file's name is the screen's size, which screen, and where the
picture goes: <screen width>x<height>-<top|bottom>-<picture width>x<height>+<x>+<y>.png
