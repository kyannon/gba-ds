# The Chinese interface

GBA DS's menus, its game list and its messages are English in the code. This
branch (`zh-cn`) adds a Chinese one: Simplified (`zh`) and Traditional
(`zh-TW`, Hong Kong and Macau included), picked in **Settings > Games >
Language**, or followed from the system (`language = auto`, the default: a
`LANG` / `LC_ALL` of `zh_CN`, `zh_TW`, `zh_HK`... picks the closest one).
English stays the default for every other system, and the setting switches
back and forth at once, without restarting.

## How a string reaches the screen

Two places translate, and nothing else in the interface does:

1. **As it is drawn.** `ui.c`'s `ui_font_text`, `ui_font_wrap` and the width
   it measures with pass every string through `tr()`. Labels that come from
   tables and structures (`config.c`'s settings, the pause menu's pages, the
   quick bar, a game's dump note) are translated there, so most of the
   interface needed no code change at all: its English is the catalogue's key.
2. **Where the code builds a string.** A sentence with a number in it
   (`"Slot %d: Empty"`), a value in a row, a long note that is wrapped: the
   format itself is passed through `tr()` where it is built
   (`snprintf(buf, n, tr("Slot %d: Empty"), slot)`). `tools/make_i18n.py
   --check` reports a `tr("...")` whose string isn't in the catalogue, so a
   typo can't leave half a sentence in English.

A format may leave out the English's **trailing** `%s`/`%d` arguments (Chinese
has no plural "s", say: `"Found %d game%s"` can be `"找到 %d 个游戏"`, and
printf ignores the extra argument). Nothing may be reordered: the arguments a
translation uses must be the English's first ones, in the same order, because
they are passed in that order.

`i18n_plural(n)` gives the English "s" (or nothing in Chinese) for the
sentences that still need one.

## The text

`assets/i18n/zh-CN.tsv` and `zh-TW.tsv`: one `English<TAB>Chinese` line each,
`#` comments and blank lines allowed, 650 lines. Both files must have the same
English lines; the tool says which one is missing what.

```
# ---- the pause menu: pages and buttons ------------------------------------
Cheats	金手指
```

Written for players, in plain words, and with one word for one thing (see the
glossary below). The English side is the string exactly as the code has it,
including its full stop and capital letters; a line the code no longer has is
reported too.

After changing either file:

```sh
tools/make_i18n.py                     # src/i18n_zh.[ch], src/i18n_zt.[ch]
tools/make_zh_font.py                  # if a new character appeared (below)
tools/embed_fonts.py                   # src/fonts_data.c
```

`tools/make_i18n.py --check` only reports: a format's arguments that don't
match, a duplicate line, an English line the code doesn't have, a `tr()` whose
string no catalogue has, and the two files' lines out of step.

`src/i18n_zh.c` and `i18n_zt.c` are generated: don't edit them. `i18n.c` does
one `bsearch` per string drawn, and the tables are written already sorted by
the tool (strcmp order).

## The fonts

Jost has no Chinese. The interface's Chinese is drawn in **Noto Sans SC**
(Simplified) and **Noto Sans TC** (Traditional), bold and regular, from Google
Fonts, under the SIL Open Font License 1.1
(`assets/fonts/NotoSansSC-OFL.txt`, `NotoSansTC-OFL.txt`).

The whole fonts are 12–17 MB, so `tools/make_zh_font.py` cuts each to the
characters its catalogue can show, plus ASCII, the arrows and quotes the menus
draw, and Chinese punctuation: **about 660 characters, about 160 KB** a weight.
A character that isn't in the font would draw as nothing, so the tool stops and
lists it. Run it again whenever a translation uses a character that wasn't
there before, then `tools/embed_fonts.py`.

**The bold face carries more.** The game list draws the names in bold, and a
name is the player's own ROM filename, which can be any Chinese: 阿拉丁, 萨尔达
传说, 火焰纹章 铠甲的呼唤, F-Zero 巅峰之战. So the bold subsets also take a
whole character set — GB2312's hanzi (6763 characters) for Simplified, Big5's
(13147) for Traditional — which is why they are about 2.1 MB and 4.7 MB instead
of 160 KB, and the zip some 7 MB bigger. A name with a rarer character than
those still can't be drawn (a box instead); the interface's own text is always
inside the catalogue's set. The ROM folder shown on the "no supported games in
…" screen is drawn in the regular face, so a Chinese path there can still show
boxes.

**A string takes the face that can draw it.** `ui.c`'s `face_for` starts from
the language's face and, if the string has a character it hasn't got, tries the
other faces and uses the one missing the fewest — so a Chinese ROM name draws
in the Chinese face even in English, and a Simplified name draws in Noto Sans
SC even in Traditional (Noto Sans TC has no Simplified glyphs at all: 纹, 铠
and 唤 are simply absent from it). The face is picked from the whole string, so
its width and its drawing agree, and text with nothing above ASCII skips the
check.

The tools need fontTools (`pip install fonttools`) and the two source fonts,
which aren't in the repo (they are 17 MB); their download URLs are in
`tools/make_zh_font.py`'s header. The subset fonts it writes *are* in
`assets/fonts/`, so a normal build needs neither.

`ui.c` picks the font for the language (`lang_font`): `TF_BOLD` and `TF_BODY`
are Jost, `TF_ZH_*` and `TF_ZT_*` the Chinese ones. The pixel font
(`ui_text`) still draws the FPS counter and version number, in Latin digits.

## Chinese line breaks

`ui_font_wrap` broke lines at spaces only, which a Chinese paragraph doesn't
have. It now breaks between characters, keeping closing punctuation (，。、；：？！
）」』…—) with the character before it, and still keeps Latin words whole. The
widths are the ones the font gives, so a line is as full as it can be.

## What stays English

- RetroAchievements' own text: achievement names, descriptions and the server's
  errors, which GBA DS doesn't write.
- Game names and paths (they are the player's data).
- `gba-ds.log`'s lines, and `bug-reports/README.txt` in a bug report, which are
  for whoever reads the report.
- The pixel font's FPS counter and version number.

## Glossary

One word for one thing, in both catalogues:

| English | 简体 | 繁體 |
|---|---|---|
| save state | 状态 | 狀態 |
| battery save | 存档 | 存檔 |
| cheats | 金手指 | 金手指 |
| patches | 补丁 | 補丁 |
| overlays | 覆盖层 | 覆蓋層 |
| bezel | 边框 | 邊框 |
| second screen | 副屏 | 副屏 |
| game list | 游戏列表 | 遊戲列表 |
| quick bar | 快捷栏 | 快捷欄 |
| settings | 设置 | 設定 |
| default | 默认 | 預設 |
| folder | 文件夹 | 資料夾 |
| screen | 屏幕 | 螢幕 |
| update | 更新 | 更新 |
| achievement | 成就 | 成就 |

The Traditional catalogue was seeded from the Simplified one with OpenCC's
`s2twp` (Taiwan phrases) and then gone over for this interface's own words
(設定, 預設, 資料夾, 螢幕, 儲存...). It is hand-kept now: change both files
together, and `tools/make_i18n.py --check` will say if one drifts.

## Checking it

- `tools/make_i18n.py --check`: the catalogues against the code (see above).
- `tools/make_zh_font.py`: every character is in the font (it stops if not).
- On the device or a desktop build: switch the language in Settings and look at
  the game list, Settings, the pause menu's seven pages, Cheats, Patches, the
  overlays screen, Hotkeys, Map Buttons and the bug report's note; a wrapped
  note (Settings > System > Updates) shows the line breaks.
